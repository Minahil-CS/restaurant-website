## 📖 Overview

**Saffron & Ember** is a responsive restaurant web application built with HTML5, Tailwind CSS, and Vanilla JavaScript. It combines a dark editorial dining aesthetic with interactive features including live menu filtering, dish inspection modals, a persistent tasting list, a filterable photo gallery with keyboard lightbox navigation, and an end-to-end table reservation workflow.

---

## ✨ Key Features

- **🍽️ Interactive Digital Menu:**
  - Filter across culinary categories (*Starters*, *Signature Mains*, *Wood-Fired & Grill*, *Desserts*, *Artisanal Drinks*).
  - Real-time search bar and dietary highlight filters (*Chef's Special*, *Vegetarian*, *Spicy*, *Gluten-Free*).
  - Dish detail modal displaying ingredients, allergens, and quick add-to-tasting-list actions.
- **🥂 Persistent Tasting List Drawer (`localStorage`):**
  - Save favorite dishes while browsing and carry your selected tasting items directly into your table reservation.
- **🛎️ Hospitality Services & Experience Cards:**
  - Highlighted dining services (*Fine Dining*, *Private Dining*, *Chef's Tasting Table*, *Catering & Events*) with one-click reservation pre-selection.
- **🖼️ Filterable Gallery & Lightbox Modal:**
  - Browse curated culinary, interior, and cocktail photography by category with previous/next controls and keyboard navigation.
- **📅 Complete Table Booking System:**
  - Select date, guest count, occasion, live service time slots, and seating ambiance (*Main Dining Room*, *Candlelit Courtyard*, *Chef's Counter*).
  - Generates a booking reference ticket (`#SE-XXXXXX`), saves bookings to `localStorage`, and supports viewing or canceling reservations via **My Bookings**.
- **📍 Contact & Location Details:**
  - Displays opening hours, contact information, and interactive map/location details.
